Walk, or look.

Without an index, a search walks the disk: folder by folder, file by file, every time you press a key. McFind walks your folders once and writes what it saw into a SQLite index. After that it only looks. File system events keep the index current.

One card per file

McFind keeps one card for every file: its name, its folder, its size and the day it changed.

A typical index of about 100,000 files takes 50 to 100 MB. Folders that only hold noise, such as caches, logs and build output, are left out. A periodic VACUUM keeps the database small.

Picture: TBurmeister (WMF), CC BY-SA 4.0, via Wikimedia Commons

Finds files while you are still typing.

Results come from a SQLite index. The goal is a full list in under 50 ms.

Searches your cloud folders too.

OneDrive, SharePoint, Google Drive and iCloud Drive are on by default.

Notices new files the moment they appear.

File system events update the index as you work. You never rescan by hand. Press Cmd+Shift+R if you ever want to.

Lets you pick every folder it reads.

Settings follow your folder tree. Switch a folder off and its children follow, or override them one by one. The Library folder is off by default.

Keeps working while it indexes.

Indexing runs in the background with a progress indicator. You can search while it runs.

Looks like it came with your Mac.

It is built with SwiftUI. Each result shows the file type, size and modified date.

Pick how to install it.

Latest release: v0.3.3. Every build is signed with a Developer ID and notarized by Apple.

Homebrew

Installs McFind and updates it with brew upgrade.

brew tap ntufar/tap
brew install --cask mcfind

DMG

Open the disk image and drag McFind to Applications.

Download McFind.dmg

PKG

An installer package that places the app for you.

Download McFind.pkg

What you need.

  • macOS 14 Sonoma or later.
  • About 100 MB of disk space for a typical index.
  • Xcode 15 or later, only if you build from source.
