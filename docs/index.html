Walk, or look?

Without an index, a search walks the disk folder by folder, every time you press a key. McFind walks your folders once and writes what it saw into a SQLite index. After that it only looks.

One little card for every file

Libraries solved this long ago. Nobody walks the shelves. They read the cards. McFind keeps one card per file: its name, its folder, its size and the day it changed.

A typical index of about 100,000 files takes 50 to 100 MB. Caches, logs and build leftovers are skipped, and a periodic VACUUM keeps the database tidy.
